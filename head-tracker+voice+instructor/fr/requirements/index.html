Head Tracker+Voice+Instructor — configuration requise

Ordinateur

  • Windows 10 ou Windows 11.
  • Les droits administrateur ne sont pas nécessaires pour l’installation.

iPhone

  • Un iPhone avec Face ID — iPhone X ou plus récent.
  • iOS 16 ou ultérieur.
  • L’application iPhone (disponible sur l’App Store après la sortie).

Connexion

  • Un câble entre l’iPhone et le PC, ou
  • l’iPhone et le PC sur le même réseau Wi-Fi.

Pour les commandes vocales

  • Le micro intégré de l’iPhone suffit.
  • Langue : anglais, français, russe, allemand ou italien.

Pour la voix de l’instructeur

  • L’instructeur parle avec une voix Windows dans votre langue. S’il reste muet, ajoutez une voix dans Windows : Paramètres → Heure et langue → Voix → Ajouter des voix.

Pas nécessaire

  • Pas de TrackIR, pas de clip IR, pas de webcam.
  • Aucun compte n’est nécessaire pour le suivi de tête, les commandes vocales ou l’instructeur.
